# 🚴 Bike Sales Analysis Dashboard | Power BI Project

## 📌 Project Overview

This project analyzes bike sales data using **Power BI** to identify customer purchasing behavior, sales trends, and business insights through interactive dashboards and visualizations.

The dashboard helps understand how factors like age, income, region, occupation, and commute distance influence bike purchases.

---

# 🎯 Objectives

* Analyze bike sales performance
* Identify customer purchasing patterns
* Create interactive dashboards
* Generate business insights using visual analytics
* Improve decision-making using data

---

| Power Query        | Data Cleaning           |
| DAX                | Calculations & Measures |
| Data Visualization | Business Insights       |

# 📂 Dataset Features

The dataset includes:

* Customer Age
* Gender
* Income
* Occupation
* Region
* Education
* Marital Status
* Commute Distance
* Bike Purchase Status

---

# 📊 Dashboard Features

✅ Sales Analysis Dashboard
✅ Customer Demographics Analysis
✅ Regional Sales Insights
✅ Income vs Purchase Analysis
✅ Interactive Filters & Slicers
✅ KPI Cards & Charts

---

# 📈 Key Insights

* Middle-aged customers purchase more bikes
* Higher income customers show higher purchasing probability
* Commute distance impacts bike purchase decisions
* Certain regions contribute more to total sales
* Customer demographics strongly influence sales trends

---

# 💡 Business Recommendations

* Target high-income customer segments
* Focus marketing on high-performing regions
* Create offers for customers with longer commute distances
* Improve customer targeting using demographic analysis
